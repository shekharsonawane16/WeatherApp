# Weather App

A responsive web-based weather application that allows users to search for a city and view current weather information using the OpenWeather API.

---

## 🔗 Live Demo

👉 [Open Weather App](https://shekharsonawane16.github.io/WeatherApp)

---

## ✨ Features

- Search weather by city name
- Current temperature
- Weather condition and description
- Weather icon
- Humidity
- Wind speed
- Feels-like temperature
- Current date
- Enter key support
- Error handling for invalid cities
- Responsive design
- Mobile-friendly interface
- PWA-ready structure

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Tailwind CSS
- OpenWeather API
- Web App Manifest

## 🌦️ Weather Information
